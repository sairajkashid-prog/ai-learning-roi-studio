## 🧮 How the ROI is calculated (transparent)

```
Total Cost          = workforce × investment per employee
Trained Employees   = workforce × 85% (real completion-rate benchmark)
Productivity Value  = trained × salary × skill-gap% × 55% effectiveness × domain demand multiplier
ROI                 = (value − cost) / cost × 100
Payback             = cost / (value / 12 months)
```

**Domain demand multipliers** come from real data — AI & ML has the highest demand-to-supply ratio (9.2M learners / 50 courses), so it gets a 1.35× multiplier.

## 🛠️ How it's built

- **Pure HTML + CSS + vanilla JavaScript** — zero external libraries, zero CDNs.
- **CSS 3D transforms** — `perspective`, `transform-style: preserve-3d`, `rotateX/Y`, `translateZ`.
- **IntersectionObserver** for scroll-triggered animations & counters.
- Self-contained `index.html` — open directly or host on GitHub Pages.
